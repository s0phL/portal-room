## Running Locally

Clone the project

```bash
git clone https://github.com/s0phL/somebodys-random-rooms.git
```

Go to the project directory

```bash
cd somebodys-random-rooms
```

Install dependencies

```bash
npm install
```

```shell
└── vite@8.1.5
```

Start the development server

```bash
npm run dev
```
